# Zwroty: co zamienić i czym

## Emocje, presja i wyrzuty → fakty i prośba

| Zamiast | Napisz |
|---|---|
| Jak już kilka razy pisałem… | Wracam do prośby z [data]: … |
| Po raz kolejny prosimy… / Znowu nie dostaliśmy… | Nadal czekamy na [materiał] (prośba z [data]). |
| Na wczoraj / ASAP / pilne!!! | Potrzebujemy [czego] do [data], ponieważ [wpływ]. |
| Nie rozumiem, czemu to tak długo trwa. | Czy mogą Państwo podać przewidywany termin [czego]? |
| To nie nasza wina, że… | Opóźnienie wynika z [fakt, data]; [wpływ]. |
| Mam nadzieję, że tym razem… | Proszę o [czynność] do [data]. |
| Oczywiście, jak zawsze… (ironia) | [usuń] |
| WIELKIE LITERY, wykrzykniki | zwykła pisownia, jedna kropka |

## Ryzykowne zobowiązania → bezpieczna forma

| Zamiast | Napisz |
|---|---|
| Gwarantujemy, że będzie gotowe do… | Planujemy zakończyć do [data], pod warunkiem [zależność]. |
| Zrobimy to bezpłatnie / gratis | [nie wprowadzaj; zaznacz autorowi do decyzji] |
| To nasz błąd, pokryjemy koszty | Przepraszamy za niedogodność. Ustalamy przyczynę i wrócimy z informacją do [data]. |
| Brak odpowiedzi uznamy za akceptację | Proszę o potwierdzenie do [data]. Do tego czasu [skutek, jeśli wynika ze szkicu]. |
| Jeśli nie, naliczymy karę / zgłosimy… | [usuń; zarekomenduj konsultację z osobą odpowiedzialną za umowę] |

## Zwroty dla trybu DUPOKRYTKA

- W nawiązaniu do rozmowy z [data] przesyłam podsumowanie ustaleń, aby mieć wspólny zapis.
- Zgodnie z decyzją [osoba / rola] z [data] realizujemy wariant [X].
- Zwracaliśmy uwagę na ryzyko [ryzyko] ([data]). Rozumiemy, że decyzja o [wariant] uwzględnia to ryzyko.
- Ta zmiana wykracza poza uzgodniony zakres; przygotujemy wycenę / prosimy o decyzję, czy ją realizować.
- Termin [etapu] zależy od [materiał / dostęp]; czekamy na niego od [data].
- Proszę o potwierdzenie powyższych punktów albo o korekty do [data]. Wystarczy odpowiedź z numerem punktu.

## Formułki do usunięcia (styl AI i wata)

- Mam nadzieję, że ta wiadomość zastaje Panią / Pana w dobrym zdrowiu.
- Warto podkreślić, że… / Należy zauważyć, że…
- Chciałbym jedynie uprzejmie przypomnieć, iż…
- W razie jakichkolwiek pytań proszę się nie wahać… (zamiast tego: „W razie pytań jestem do dyspozycji.”)
